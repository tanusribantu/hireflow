# HireFlow

**Job Recruitment Portal with Real-Time Application Tracking and ATS Matching**

HireFlow is a two-sided recruitment platform. Candidates build profiles, scan their resumes for skills, apply to jobs and track every application through to a decision. Recruiters post jobs and move applicants through a Kanban pipeline, with an explainable match score on every card.

> Status: in development. A Foundation Project for the Department of Computer Science and Engineering (AI&ML), A.Y. 2026-2027.

## Features

### Candidates
- Profile builder with skills, experience, education and resume upload
- **Resume scanner**: detects skills in an uploaded resume and lets the candidate choose which ones to add
- Job browsing with filters, and a "Verified Company" badge on listings
- One application per job, with a stage tracker (New, Screening, Interview, Offer, Rejected)
- Rejection reasons are always shown, whether written by the recruiter or generated by the system
- **Bucket list**: save jobs without applying, and get notified before their deadlines

### Recruiters
- Job posting with required skills, each marked *nice-to-have* or *must-have*
- Per-job toggle to enable or disable ATS matching
- Application deadlines that can be extended or brought forward
- Kanban pipeline with a match score (Strong / Partial / Low) on every applicant, and filtering by score band
- Quick-select rejection reasons at the screening stage
- Company verification through a company-email confirmation link (generic domains such as gmail.com are rejected)

## ATS matching engine

The matching service is a standalone **C++ microservice** (`cpp-httplib` + `nlohmann/json`) that the web app calls over HTTP.

Each matched skill contributes `evidence weight x importance weight`:

| Candidate evidence | Weight | Job skill importance | Weight |
|---|---|---|---|
| Self-reported | 1 | Nice-to-have | 1 |
| Project-backed | 2 | Must-have | 3 |
| Quiz-verified | 3 | | |

```
score = (sum of evidence x importance over matched skills)
        / (sum of 3 x importance over all required skills) x 100
```

| Score | Band |
|---|---|
| above 70 | Strong |
| 40 to 70 | Partial |
| below 40 | Low |

The engine is deliberately **rule-based and deterministic, not machine learning**. Every score can be traced back to the skills that produced it, and there is no model to train, host or pay for. The resume scanner works the same way, matching keywords against a known-skills list.
